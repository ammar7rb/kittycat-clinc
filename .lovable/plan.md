
# خطة تحويل "الخدمات" إلى متجر (Shop)

## 1. قاعدة البيانات (Migration)
إنشاء جدول `products` جديد:
- `id`, `name_ar`, `name_en`
- `description_ar`, `description_en`
- `price` (رقم) ، `compare_at_price` (السعر قبل الخصم - اختياري)
- `currency` (افتراضي: SAR)
- `image_url`, `category` (food / accessories / toys / health)
- `pet_type` (cat / dog / both)
- `brand`, `stock` (الكمية)
- `is_featured` (منتج مميز)
- `is_active`, `sort_order`, `created_at`, `updated_at`
- مع GRANT + RLS (قراءة عامة، كتابة للأدمن فقط)

الإبقاء على جدول `services` كما هو (لاستخدامه في الصفحة الرئيسية لقسم "خدماتنا الطبية").

## 2. الراوتس
- حذف `src/routes/services.tsx`
- إنشاء `src/routes/shop.tsx` — صفحة المتجر (شبكة منتجات + فلاتر بسيطة: الكل / قطط / كلاب + بحث)
- إنشاء `src/routes/shop.$productId.tsx` — صفحة تفاصيل المنتج
- تحديث الهيدر: "الخدمات" → "المتجر / Shop"
- تحديث الفوتر والروابط في `index.tsx`

## 3. لوحة الأدمن
- إنشاء `src/routes/_authenticated/admin/products.tsx` — قائمة + إضافة + تعديل + حذف + رفع صورة (لـ bucket `media`)
- إضافة "المنتجات" في `AdminSidebar`
- (الإبقاء على صفحة admin/services للخدمات الطبية)

## 4. المكونات
- `src/components/site/ProductCard.tsx` — بطاقة منتج احترافية (صورة، اسم، علامة، سعر مع شطب السعر القديم، زر "اطلب عبر واتساب" + زر "تفاصيل")
- `src/components/site/ProductGrid.tsx` للعرض

## 5. توليد 5 منتجات + صورها
أمثلة:
1. طعام جاف للقطط البالغة - Royal Style 2kg
2. طعام رطب للقطط - Tuna & Salmon 12 علبة
3. طعام جاف للكلاب الصغيرة - Puppy Premium 3kg
4. مكمل فيتامينات للقطط
5. لعبة تفاعلية + عمود خدش للقطط

سيتم توليد صور احترافية لكل منتج وحفظها كـ assets، ثم إدراجها في الجدول.

## 6. اقتراح التصميم (3 اتجاهات)
بعد بناء البنية، سأعرض 3 اتجاهات تصميم لبطاقة المنتج وشبكة العرض لتختار منها (نفس أسلوب البوتيك الموجود — Cairo font، تيل + برتقالي، gradients ناعمة).

## ملاحظات تقنية
- الأسعار بالريال السعودي (SAR)
- زر "اطلب الآن" يفتح واتساب مع رسالة جاهزة فيها اسم المنتج والسعر
- لا توجد عربة شراء (cart) أو دفع إلكتروني الآن — الطلب عبر واتساب فقط. إن أردت إضافة عربة + دفع لاحقاً، نضيفها كمرحلة ثانية.
