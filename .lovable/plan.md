
# خطة تنفيذ مشروع Kitty Cat Clinic

## 1. ملخص سريع للفهم

- **المشروع:** موقع تعريفي لعيادة بيطرية متخصصة في القطط باسم "Kitty Cat Clinic"، مع لوحة تحكم إدارية في نفس المشروع.
- **الجمهور:** أصحاب القطط في الإمارات (3 فروع: الرقام، الصنب، الرحبة).
- **الهدف الأساسي:** عرض الخدمات والعروض والفروع، وتحويل كل أزرار CTA إلى واتساب (رقم مختلف لكل فرع).
- **الصفحات العامة:** الرئيسية، الخدمات، من نحن، تواصل معنا.
- **اللغات:** لغة افتراضية واحدة + زر تبديل في الهيدر (LTR/RTL ديناميكي). سأقترح العربية كافتراضية بحكم الجمهور — بانتظار تأكيدك.
- **لوحة التحكم:** ضمن نفس المشروع تحت `/admin`، دور واحد (Admin)، تسجيل دخول فقط، CRUD لـ: الخدمات، العروض، الفروع، محتوى الموقع، الوسائط.
- **التقنيات:** TanStack Start + Lovable Cloud (قاعدة بيانات، Auth، Storage) — بديلًا لـ Laravel/MySQL المذكور في الـ PRD.
- **التصميم:** ألوان `#0e8281` (أساسي) و`#ed8232` (ثانوي) فقط — **بدون الأحمر `#d93b3b` نهائيًا** حسب طلبك. خط Cairo للعربي وInter للإنجليزي. تصميم هادئ مينيمال مع Framer Motion.
- **المحتوى:** نصوص احترافية مولّدة الآن (عربي/إنجليزي) كـ placeholders، صور حقيقية لاحقًا (بدون صور AI)، اللوجو والأرقام والتفاصيل سترسلها لاحقًا.
- **نموذج التواصل:** يحوّل إلى واتساب (لا form تقليدي).
- **SEO:** كامل من البداية (Meta tags، Sitemap، Robots، Schema.org، Open Graph).
- **الواتساب العائم:** زر ثابت + رسائل مهيّأة مسبقًا.

## 2. تقسيم المشروع إلى Milestones

### Milestone 1: التأسيس وقاعدة البيانات

**الهدف:** تجهيز البنية التحتية الكاملة (Lovable Cloud، الجداول، الـ Auth، نظام اللغات، نظام التصميم).

**النتيجة المتوقعة:** مشروع جاهز تقنيًا مع قاعدة بيانات منشأة، نظام تصميم موحّد، وآلية تبديل لغة تعمل.

**Tasks**

- **Task 1: تفعيل Lovable Cloud وإنشاء المخطط**
  - تفعيل Lovable Cloud
  - إنشاء جدول `services` (الاسم AR/EN، الوصف AR/EN، الأيقونة/الصورة، الترتيب، نشط/مخفي)
  - إنشاء جدول `offers` (العنوان AR/EN، الوصف، الصورة، تاريخ البدء/الانتهاء، نشط)
  - إنشاء جدول `branches` (الاسم AR/EN، العنوان، رقم الهاتف، رقم الواتساب، رابط Google Maps، الإحداثيات، ساعات العمل)
  - إنشاء جدول `website_content` (key/value لكل النصوص القابلة للتعديل)
  - إنشاء جدول `media` (للوسائط المرفوعة)
  - إنشاء جدول `user_roles` + enum للأدوار + دالة `has_role` security definer
  - تفعيل RLS + سياسات: قراءة عامة للجداول العامة، كتابة للـ admin فقط
  - GRANTs مناسبة (anon: SELECT للجداول العامة، authenticated: كامل عبر RLS)

- **Task 2: نظام التصميم (Design Tokens)**
  - تعريف ألوان الـ brand في `src/styles.css` بصيغة OKLCH:
    - `--primary` = `#0e8281` (تركوازي)
    - `--secondary` = `#ed8232` (برتقالي)
    - **حذف/استبدال أي مرجع للأحمر `#d93b3b`**
    - تدرجات + ظلال خفيفة + radius
  - إعداد الخطوط: Cairo (عربي) + Inter (إنجليزي) عبر Google Fonts
  - Dark/Light tokens (الافتراضي Light)
  - إعداد `globals` للـ RTL (direction switching)

- **Task 3: نظام اللغات (i18n)**
  - إنشاء `LanguageProvider` (Context) يدير اللغة الحالية + dir
  - حفظ التفضيل في localStorage
  - ملفات ترجمة `ar.json` و`en.json` (مفاتيح فارغة جاهزة)
  - Hook `useT()` للترجمة
  - تبديل تلقائي لـ `<html lang>` و`dir`
  - زر التبديل في الهيدر (AR ⇄ EN)

- **Task 4: نظام المصادقة للـ Admin**
  - صفحة `/admin/login` (Email + Password فقط)
  - حماية مسارات `/admin/*` تحت `_authenticated`
  - إنشاء أول حساب Admin يدويًا (بانتظار إيميل المسؤول منك)
  - منطق `has_role(uid, 'admin')` للتحقق

**Review Checkpoint**
- هل العربية كلغة افتراضية مناسبة؟
- هل هيكل قاعدة البيانات يغطي كل متطلباتك؟
- هل تفضل اسمًا/إيميلًا محددًا لحساب الـ Admin الأول؟
- هل توافق على الانتقال للـ Milestone 2؟

### Milestone 2: المكونات المشتركة (Layout + Shared Components)

**الهدف:** بناء الهيكل العام الذي تستخدمه كل صفحات الموقع.

**النتيجة المتوقعة:** هيدر، فوتر، زر واتساب عائم، Layout كامل جاهز يُلف حول كل الصفحات.

**Tasks**

- **Task 1: الهيدر (Header)**
  - شعار (placeholder مؤقت لحين إرسال اللوجو)
  - روابط: الرئيسية، الخدمات، من نحن، تواصل
  - زر CTA "احجز عبر واتساب"
  - زر تبديل اللغة AR/EN
  - تجاوب كامل + قائمة موبايل (Sheet)

- **Task 2: الفوتر (Footer)**
  - معلومات العيادة المختصرة
  - روابط الفروع الثلاثة (الرقام، الصنب، الرحبة)
  - أرقام التواصل (placeholders)
  - السوشيال ميديا (placeholders)
  - حقوق النشر

- **Task 3: زر الواتساب العائم**
  - يظهر على كل الصفحات
  - يفتح قائمة لاختيار الفرع (3 فروع، كل فرع برقمه)
  - رسالة مهيّأة مسبقًا حسب الصفحة الحالية
  - أنيميشن دخول لطيف

- **Task 4: مكونات قابلة لإعادة الاستخدام**
  - `SectionHeading` (عنوان قسم موحّد)
  - `ServiceCard`
  - `OfferCard`
  - `BranchCard`
  - `WhatsAppButton` (variants)

**Review Checkpoint**
- هل ترتيب عناصر الهيدر مناسب؟
- هل تريد قائمة فروع منسدلة في زر الواتساب أم زر مباشر لرقم واحد رئيسي؟
- هل توافق على الانتقال للـ Milestone 3؟

---

### Milestone 3: الصفحات العامة

**الهدف:** بناء الصفحات الأربع الرئيسية بمحتوى ديناميكي من قاعدة البيانات.

**النتيجة المتوقعة:** موقع كامل قابل للتصفح بنصوص احترافية مولّدة وصور placeholder.

**Tasks**

- **Task 1: الصفحة الرئيسية `/`**
  - Hero section (عنوان رئيسي + CTA واتساب)
  - قسم الخدمات (أبرز 4-6 خدمات من DB)
  - قسم العروض النشطة
  - قسم "لماذا نحن"
  - قسم الفروع الثلاثة (cards مع Maps preview)
  - شهادات/Trust signals (اختياري — بحاجة لتأكيدك)
  - أنيميشن Framer Motion عند Scroll

- **Task 2: صفحة الخدمات `/services`**
  - شبكة كل الخدمات من DB
  - كل خدمة: أيقونة/صورة + اسم + وصف + زر "احجز عبر واتساب"
  - تصفية حسب الفئة (اختياري)

- **Task 3: صفحة من نحن `/about`**
  - قصة العيادة، الرؤية، الرسالة
  - الفريق (اختياري — بانتظار صور حقيقية)
  - الفروع الثلاثة بالتفصيل

- **Task 4: صفحة التواصل `/contact`**
  - بطاقة لكل فرع: اسم + عنوان + هاتف + واتساب + خريطة Google Maps embedded + ساعات العمل
  - أزرار CTA واتساب لكل فرع
  - **لا يوجد form تقليدي** (تحويل مباشر لواتساب)

- **Task 5: SEO Setup**
  - `head()` لكل route (title, description, OG, Twitter)
  - `sitemap.xml` ديناميكي
  - `robots.txt`
  - JSON-LD: Organization + LocalBusiness (لكل فرع) + Service
  - alt للصور، h1 واحد لكل صفحة

**Review Checkpoint**
- هل تريد قسم شهادات/تقييمات في الرئيسية؟
- هل تريد قسم "الفريق" في صفحة من نحن؟
- هل النصوص المولّدة جاهزة للمراجعة قبل الـ Milestone التالي؟
- هل توافق على الانتقال للـ Milestone 4؟

---

### Milestone 4: لوحة التحكم (Admin Dashboard)

**الهدف:** تمكينك من إدارة كل محتوى الموقع بدون تدخل تقني.

**النتيجة المتوقعة:** داشبورد كامل تحت `/admin` مع CRUD لكل البيانات.

**Tasks**

- **Task 1: هيكل الداشبورد**
  - Layout مع Sidebar (Shadcn) + Header
  - Dashboard home (إحصائيات سريعة: عدد الخدمات، العروض النشطة، إلخ)
  - زر تسجيل خروج

- **Task 2: إدارة الخدمات**
  - جدول بكل الخدمات
  - إضافة/تعديل/حذف
  - رفع أيقونة/صورة
  - تفعيل/إخفاء + ترتيب (drag & drop اختياري)

- **Task 3: إدارة العروض**
  - جدول بالعروض
  - إضافة/تعديل/حذف
  - تواريخ بدء وانتهاء
  - رفع صورة
  - حالة (نشط/منتهي تلقائيًا)

- **Task 4: إدارة الفروع**
  - تعديل بيانات كل فرع (اسم، عنوان، هاتف، واتساب، خريطة، ساعات عمل)

- **Task 5: إدارة محتوى الموقع**
  - تعديل نصوص الصفحات الثابتة (Hero, About, إلخ) بـ AR/EN
  - تعديل الـ logo والـ favicon
  - تعديل روابط السوشيال ميديا

- **Task 6: إدارة الوسائط**
  - مكتبة صور (Lovable Cloud Storage)
  - رفع/حذف
  - استخدام في الخدمات/العروض

**Review Checkpoint**
- هل تريد سجل تغييرات (audit log)؟
- هل تحتاج تصدير بيانات (CSV)؟
- هل توافق على الانتقال للـ Milestone 5؟

---

### Milestone 5: التشطيب والإطلاق

**الهدف:** صقل المشروع وضمان الجاهزية للنشر.

**النتيجة المتوقعة:** موقع نهائي مصقول وجاهز للإطلاق.

**Tasks**

- **Task 1: استبدال المحتوى المؤقت**
  - رفع اللوجو الحقيقي (عند استلامه)
  - استبدال الصور الـ placeholder بصور حقيقية (عند استلامها)
  - مراجعة وتحديث كل النصوص النهائية

- **Task 2: الأداء**
  - Lazy loading للصور
  - Code splitting
  - تحسين Lighthouse score

- **Task 3: المراجعة الشاملة**
  - اختبار كل الروابط
  - اختبار RTL/LTR
  - اختبار على موبايل/تابلت/ديسكتوب
  - اختبار كل أزرار الواتساب
  - اختبار CRUD في الداشبورد

- **Task 4: SEO Final Check**
  - تشغيل SEO scan
  - معالجة كل الملاحظات
  - Submit sitemap

- **Task 5: النشر**
  - Publish عبر Lovable
  - ربط Custom Domain (لاحقًا عند استلامه)

**Review Checkpoint**
- هل كل المحتوى النهائي جاهز؟
- هل توافق على النشر؟

## 3. مراجعة شاملة قبل التنفيذ

### الصفحات المطلوبة
1. `/` الرئيسية
2. `/services` الخدمات
3. `/about` من نحن
4. `/contact` تواصل معنا
5. `/admin/login` تسجيل دخول الإدارة
6. `/admin` لوحة التحكم الرئيسية
7. `/admin/services` إدارة الخدمات
8. `/admin/offers` إدارة العروض
9. `/admin/branches` إدارة الفروع
10. `/admin/content` إدارة محتوى الموقع
11. `/admin/media` مكتبة الوسائط
12. صفحة 404

### الوظائف المطلوبة
- تبديل لغة AR/EN مع RTL/LTR ديناميكي
- زر واتساب عائم مع اختيار فرع
- رسائل واتساب مهيّأة مسبقًا حسب السياق
- Google Maps embedded لكل فرع
- CRUD كامل من الداشبورد
- مصادقة آمنة للـ Admin
- SEO كامل + Sitemap ديناميكي
- رفع وإدارة الوسائط

### عناصر الداشبورد
- Sidebar navigation
- Dashboard home بإحصائيات
- 5 شاشات إدارة (Services, Offers, Branches, Content, Media)
- مكتبة وسائط
- نظام تسجيل دخول/خروج

### عناصر التصميم وتجربة المستخدم
- لون أساسي `#0e8281` + ثانوي `#ed8232` فقط (بدون أحمر)
- خط Cairo (AR) + Inter (EN)
- Framer Motion animations
- Light theme افتراضي
- Responsive كامل
- Shadcn UI components

### اللغات والاتجاهات
- العربية (افتراضية مقترحة) — RTL
- الإنجليزية — LTR
- زر تبديل في الهيدر

### الافتراضات المستخدمة
1. **العربية كلغة افتراضية** (بحكم الجمهور الإماراتي) — بحاجة لتأكيدك
2. **استبدال كامل لـ Laravel** بـ Lovable Cloud
3. **عدم وجود قسم Blog/Articles** (غير مذكور في PRD)
4. **عدم وجود نظام حجز مواعيد** (كل شيء عبر واتساب)
5. **رفع الصور عبر Lovable Cloud Storage** (لا CDN خارجي)
6. **حساب Admin واحد فقط** يُنشأ يدويًا

### يحتاج موافقة نهائية منك
- ✅ اللغة الافتراضية (عربي أم إنجليزي)
- ✅ وجود/عدم وجود قسم شهادات في الرئيسية
- ✅ وجود/عدم وجود قسم الفريق في من نحن
- ✅ شكل زر الواتساب العائم (قائمة فروع أم رقم رئيسي واحد)
- ✅ إيميل حساب الـ Admin الأول
